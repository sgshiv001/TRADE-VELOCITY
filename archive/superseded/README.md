# Superseded release files

This archive contains the retired Expo and Capacitor Android clients, the old Capacitor dependency lock, and the configurations for separate Windows admin, trader, and setup binaries. They are kept for history. The active release builds one Windows x64 executable and deploys the web workspace.

Historical binaries remain attached to their original GitHub releases. The [release list](https://github.com/sgshiv001/TRADE-VELOCITY/releases) preserves their tags and checksums.
