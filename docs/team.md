# The TradeVelocity team

We are **Hash Syndicate**, a four-person group from Bennett University. We built TradeVelocity for our Advanced Data Structures and Algorithms project and worked together to bring the matching engine, interface, saved workspaces, and project checks into one app.

For our group presentation, we divided the explanation into these areas:

| Member | Presentation area |
| --- | --- |
| Shivanshu Gupta | Matching rules, core engine, fills, cancellations, and correctness checks |
| Aditya Verma | React interface, themes, order entry, and market views |
| Sourabh Gupta | Backend integration, saved sessions, workloads, and performance comparison |
| Harshit Sharma | AI monitoring, validation, tests, and documentation |

These areas come from our project report. They show how we presented the shared work; they are not a claim that each person alone wrote the corresponding files.

Want to see the project in action? [Open the web app](https://gettradevelocity.onrender.com), read the [short demo guide](adsa-demo.md), or return to the [project overview](../README.md).
