# Trade Velocity Classroom Demo

For the full app, run from the repository root:

```powershell
python app.py
```

You can also double-click `app.bat` in Windows or select **Trade Velocity:
Run App** in VS Code's Run and Debug menu and press F5. Choose Edge, Chrome,
Firefox, or the system default browser at the prompt. The launcher builds the
frontend, starts the API, and opens the dashboard once it is ready. Keep the
terminal open and press Ctrl+C to stop.

To include a deterministic terminal walkthrough before opening the app, use:

```powershell
python class_demo.py
```

The classroom launcher:

1. Prints a deterministic walkthrough of multi-level matching and partial
   execution.
2. Starts the local FastAPI + React application if it is not already running.
3. Asks for a browser and opens the app at `http://127.0.0.1:8000/`.
4. Keeps the server alive until `Ctrl+C`.

For a terminal-only rehearsal:

```powershell
python class_demo.py --terminal-only
```

To start the app without opening a browser:

```powershell
python app.py --no-browser
```

## Suggested presentation sequence

### 1. Engine

Click **Load demo flow**. Explain that the incoming buy order checks the best
compatible sell order, executes at the resting order's price, and continues
until filled or liquidity is exhausted.

### 2. Order Book

Select a price level. Point out the price, quantity, order count, FIFO queue,
and `Price → Time` priority rule.

### 3. DSA Lab

Use the tabs to show a max heap, AVL tree rotations, separate chaining, FIFO
dequeue order, and Fenwick prefix sums. These are educational visualizations of
the structures used by the engine.

### 4. Simulator

Choose a scenario and start the workload. State clearly that the values are
synthetic simulation counters, not market predictions.

### 5. AI Monitor

Explain the pipeline: dated historical market data → feature engineering →
Isolation Forest → anomaly score. The model scores the same historical window
used for fitting; these are educational anomaly flags, not live predictions.

### 6. Benchmark

Only present rows that have been generated by an actual benchmark. Empty values
are intentional and are not replaced with invented performance claims.

## Troubleshooting

- If the app is already running, the launcher reuses it.
- If port 8000 is busy with another service, use `python app.py --port 8010`.
- If Python packages are missing, run `.venv\Scripts\python.exe -m pip install
  -e ".[app]"` from the project folder.
- For a faster launch using the last frontend build, add `--skip-build`.
- If the browser does not open, visit `http://127.0.0.1:8000/` manually and
  use `--no-browser`.
- Stop the demo with `Ctrl+C`.
